# 专职切片制作子 Agent (Subagent) 派发规范

本模板集中管理子 Agent 派发时的系统提示词与输入约束。子 Agent 依据主 Agent 预先建立的原文骨架和依赖表起草学习单元，不得自行重排跨单元的数学顺序。本文件是切片写作者执行口径（任务包、小问判定、揭示边界/证明支架/microknowledge/文风）的权威维护位置；运行状态机与交付门禁归 `../references/production.md`，TeX 接口细节归 `../references/tex-interface.md`。

---

## 写作者任务包清单（派发时固定提供，不多不少）

切片写作者最终只收到以下任务包；凭此即可完成任务，**无需阅读完整生产状态机**（production.md）或课堂实施文件：

```text
1. 当前任务身份：run_id / task_id / attempt_id / input_digest（取自 pdstate start 冻结的 task.json）。
2. 本节原文片段及可定位来源。
3. 本节目标、学生已知前置、输入/输出概念接口。
4. 本节实际规划节点、qid、小问动作和首次反馈位置。
5. 本节已批准材料；无材料时显式给空包。
6. 本次需要的 TeX 接口摘录（references/tex-interface.md「写作者速查」）。
7. 对话开关及本节蓝图；关闭时不发送对话写作细则。
8. 独占输出路径、提交格式、必要自查。
```

## 子 Agent 派发参数配置（成本约束）

执行切片的子 Agent 使用**低成本档位**模型，以控制大规模章节生成成本；实际模型名由宿主已配置的映射提供，不硬编码一个宿主不存在的接口（宿主适配层负责路由校验，不得自动回退到更贵模型）。主 Agent 与切片 Agent 遵守相同的输入、输出和验收规则；主 Agent 负责全局规划与数学审校。若需补充材料中缺失的引例或反例，由研究核验 Agent（见 `research_prompt.md`）提交候选卡片，主 Agent 经来源闸门与数学/教学闸门核验后，以按切片筛选的批准材料包（`material-pack-secN.md`）提供；切片 Agent 只能使用其中状态为 `approved` 的卡片，不得自行检索或编造来源。
- `TypeName`: `"self"`
- `Model`: `<由宿主已配置映射提供的低成本模型名>`（必须显式指定）
- `Role`: `"§X.X 切片制作专员"`

## 派发提示词模板 (Prompt Template)

```markdown
你是一名专职的数学教研子 Agent，负责将原材料切片重构为“纯问题驱动 (Problem-Driven)”的 LaTeX 导学案切片。

## 输入约束
- 原材料文件：{{INPUT_FILE}}
- 处理行范围：第 {{START_LINE}} 行 至 第 {{END_LINE}} 行
- 小节标题：{{SECTION_TITLE}}
- 输出目标文件：{{OUTPUT_FILE}}（位于主 Agent 用 `pdstate.py start` 创建的独占候选目录，如 self/.pd/candidates/sec1/attempt-0001/sec1.tex；同目录另需提交 result.json）
- 章节叙事锚点：{{NARRATIVE_ANCHOR}}
- 上一节出口：{{PREVIOUS_BRIDGE}}
- 本节出口/下一节入口：{{NEXT_BRIDGE}}
- 可复用反例台账：{{COUNTEREXAMPLES}}
- 证明策略台账：{{PROOF_STRATEGY}}
- 批准材料包：{{APPROVED_MATERIAL_PACK}}
  （空包 = 无批准卡片，仅用原文材料写作；缺包 = 主 Agent 未提供材料包，返回缺口清单，不得动笔）

## 严格执行规范
0. 主 Agent 已提供 `source-map.md`、`dependency-map.md` 和 `coverage-map.md`。先阅读与本切片有关的记录；如果记录缺失或依赖标为"待审"，只返回问题清单，不要生成题目。**写作前先提交压缩卡：本节目标动作、候选载体题、合并组、移入题库的 qid、每题认知动作与预估台阶**。**每个载体题只允许一个主要认知动作；同一 `reuse_group` 的变式不得重复讲完整方法**。材料输入只使用 {{APPROVED_MATERIAL_PACK}} 中状态为 `approved` 的卡片；**正文不得出现卡片 ID、来源核验标签或研究过程说明**。若材料包不足，返回缺口清单和所需字段，不得自行检索或编造。依赖闭合一律按**学生实际可见内容**检查：仅在教师版出现的结论不构成学生侧依赖闭合。
1. 切片文件绝对不要包含 \documentclass、导言区或 \begin{document} / \end{document}。
2. 直接以 \section*{{{SECTION_TITLE}}} 开头。小节标题统一以大写罗马数字加空格开头（`I `、`II `、`III `……），形如 `\section*{I 小节标题}`，编号由主 Agent 派发时随 {{SECTION_TITLE}} 给出，严禁使用中文数字（一、二、三）、顿号或其他编号样式。依据叙事锚点决定是否加入引例或历史背景；引例必须导向明确数学任务。需要保持动机、术语或跨节连贯性的短 exposition 应保留。材料段落必须在材料包给定的长度预算内，材料后立即出现可完成的数学动作，不得把后续小节内容提前讲完。
3. 所有题目统一置于 \begin{probchain} ... \end{probchain} 环境中，由内置计数器自动跨节连续编号（严禁自行重置计数器或使用版本开关宏：不得出现 \setcounter{pdprob}、\def\TeacherVersion、\ifdefined\TeacherVersion）。每个一级 \item 前必须有 `% qid: <稳定题ID>` 注释（与 coverage-map.md 登记的 qid 一致，全章唯一）；显示题号是渲染结果，不得手填。
4. 不得机械凑齐固定题型。按原文节点的实际依赖选择必要环节；反例必须改变明确条件并说明保留/破坏的性质，不能为了覆盖题型凭空添加。
5. 题型标签一律使用 \qtype{进入题}、\qtype{证明题} 等宏命令（教师版显示【xx题】，学生版自动隐藏）。
6. 必须为每道题配备 \begin{solution}...\end{solution} 以及 \begin{teacherNote}...\end{teacherNote}，并配 \ansspace{...} 留白。填空一律使用**选择题化填空** `\fillin[答案]{宽度}[选项1/选项2/选项3]`：保留原有下划线填空框架，在每个空之后追加若干简短选项，学生可直接圈选选项完成填空。选项以 `/` 分隔；每个选项必须简短（单个数值、短式、词或短语）；至少 3 个；参考答案必须是选项之一；干扰项取自初学者典型错误或易混对象，不得放明显荒谬的凑数项。
   - **代数结构与分式排版保护**：选项内若含数学斜杠（如商群、商环、分式域），必须使用 `{}` 花括号包裹保护（如 `{\mathbf{Z}/p\mathbf{Z}}`、`{\mathbf{Q}_p^*/\mathbf{Q}_p^{*2}}`），或使用转义符 `\/`（如 `\mathbf{Z}\/p\mathbf{Z}`），或优先使用标准数学宏 `\quotgrp{G}{H}` 与 `\quotring{R}{I}`。严禁裸露未保护的 `/` 导致选项错误切分！
   - **消灭伪自学与猜谜填空**：严禁“题干宣读性质/充要条件，末尾挖空填常数 0、1 或定理名字”的降智伪自学填空（例如：“充要条件为三阶行列式等于：\fillin[$0$]”）。单一切片中答案为常数（0/1/-1）的填空占比不得超过 20%。填空考查的内容必须是学生亲手算出的具体数值、化简后的关键代数式或核心几何判据。
   - **自适应答题留白规范 (Adaptive \\ansspace)**：消除对长题留白导致排版膨胀断页的恐惧，按小问运算量梯度配置留白：
     - 简短代数表达式或选项填空小问：配置 `\ansspace{0.5cm}`；
     - 中等推导小问（1~2 行公式计算）：配置 `\ansspace{1.0cm}`；
     - 复杂行列式展开或大证明小问：配置 `\ansspace{1.5cm}`；
     - 一道 6 问的长题，总留白高度严格控制在 5.0cm 以内，完美适配大 8 开双栏版面。
7. 多问小题（含所有证明题）使用嵌套 enumerate 排布各小问，每一问各自紧跟自适应 \ansspace{...} 留出相应书写空间。
   - **双轨递进题型架构规范 (Dual-Track Problem Framework)**：彻底废除单一的“机械 3 问”定式，根据教学功能严格区分两类题型：
     - **类型 A：概念夯实与算例演练题（2–3 问）**：
       - **算例先行与直观探究 (Example-First Exploration)**：引入新概念、新几何运算（如叉乘、Conway 加权度量、EFFT）后，**第一道题必须设计具体数值或简单整数坐标/特殊三角形边长（如 3,4,5 直角三角形）的验算**，让学生在动手验算中直观观察公式运作，建立手感与确定感；
       - 台阶结构：(a) 概念/公式代入识别 -> (b) 具体数值代入试算 -> (c) 逆向检验或退化特例。
     - **类型 B：大定理探究与长链推导题（长链导学大题，4–7 问）**：
       - **适用场景**：核心大定理证明（如 Routh 定理、Ceva 定理、EFFT 垂直对称判据、垂线方程代数求解）；
       - **【严禁题干包办推导红线】**：题干叙述只允许交代初始几何设定与最终证明目标，一级 \item 题干文本在 \begin{enumerate} 之前不得超过 120 汉字，**严禁在题干中罗列求解好的中间方程、中间交点坐标或化简结果**！
       - **长链微步阶梯 (Micro-stepping Scaffolding)**：必须拆解为包含 (a) 到 (f) 至少 4~7 个连续递进的小问台阶（由 `check_pedagogy` 门禁强制校验），长题耗时由流水线根据小问数与填空数确定性估算，严禁为了缩短篇幅省略推导台阶！（如：第 1 步参数化分点坐标；第 2 步叉乘求出单条直线；第 3 步联立求解关键交点；第 4 步轮换对称写出其余各点及分母；第 5 步展开三阶行列式并化简；第 6 步定量面积比公式建立；第 7 步取特例退化导出共点定理）。让学生在草稿纸上算齐每一步，最终亲手推导出定理，形成完全自足的自学顿悟！
8. **知识自足性、微型知识卡与章节结论框（硬性门禁）**：
   - 题目前必须提供其所需的对象、运算、记号、维数条件和前置结论；不能用"先探究"掩盖缺少定义，也不能用"将在后续小节定义"豁免当前题所需的前置。
   - **前置定义卡 (`microknowledge`)**：凡题目引入新概念、新滤过、新代数对象或非平凡记号，该题之前必须紧邻至少 1 个 `\begin{microknowledge}[核心定义与记号]...\end{microknowledge}` 实线框。一张卡解决一个当前必需的定义或记号。
   - **章节末结论框 (`knowledgebox`)**：每个切片末尾必须包含 `\begin{knowledgebox}[本节结论]...\end{knowledgebox}` 虚线框，梳理本节由问题链自主探究推出的核心定理、同构分解或判据，形成认知闭环并给出下一节接口。
   - `scripts/check_numbering.py` 与 `scripts/check_pedagogy.py` 实施硬门禁检查：切片缺少 `microknowledge` 或 `knowledgebox` 将被直接拦截拒绝合流！
8b. **揭示边界、任务有效性与绝对防剧透 (Zero Answer Leakage in Stems)**：
   - **防剧透红线**：题干叙述必须提出思考方向或引导动作，**严禁在填空题干紧邻语境中直接写出待填答案或结论本身**（如“答案为 $X$，填空：\fillin[$X$]”或“即为 $X$，形式为：\fillin[$X$]”），严禁把推导关键细节在题干中剧透完毕只留最后一个词让学生填。
   - 揭示边界按小问及其学习目标判断。写作前明确：学生已经得到什么、该小问仍需完成什么、完成后何处核对。如果此前对白、叙述、策略或其他小问已经完成该小问唯一的数学动作，则删除重复小问、改写为新任务，或明确作为已解示例。
9. **课堂优先级、知识密度加权与弹性题量规划**：
   - **废除机械等额规划**：彻底废除“每章固定 4 节、每节机械均分 5 道题、每题固定 3 问”的教条主义。切片与题量必须根据原文知识密度弹性分配：
     - 低密度/概念与计算引入节：3–4 道直观探索题即可，避免无病呻吟凑题；
     - 高密度/定理证明与结构分类节：允许上调至 6–8 道阶梯式引理题，或拆分为更细粒度子切片（如 `sec3a` 与 `sec3b`），严禁为凑 5 题上限而粗暴压缩证明细节、跳过关键台阶！
   - **题块元数据**：每道题注释必须保留 `% qid: <稳定题ID>`，在 coverage-map.md 中保留 `delivery_role` (`core`/`support`/`self-study`/`reference`)。题目的耗时由流水线确定性结构估算引擎（`scripts/estimate_minutes.py`）根据切片内部结构特征（小问数与填空数）自动计算，子 Agent 无需手动估算编数；coverage-map.md 的 `planned_minutes` 说明更新为可选字段（仅用于教师显式覆盖 `teacher_override`，默认留空或由流水线自动标注）。
   - `teacherNote` 只写本题独有的追问、判据或易错点；重复方法移入章节级教师备注。
   - **题目压缩原则**：同方法的换数据练习、重复变式进入 `self-study`；每个方法族只保留一个课堂载体题；一个载体题可在 coverage-map.md 中承接多个原文节点，通过 `carrier_qid` 标记复用关系。
10. 文风简明严谨与概念克制：全篇必须使用简明、严谨、严肃的数学学术文风，严禁使用口语化、戏谑调侃、网络梗或夸张修辞（严禁出现"罪魁祸首"、"单身狗"、"雪崩"、"合宪性"等）。注意：严谨不意味着引入过多额外的概念，严禁脱离主线强行堆砌不必要的高级概念，只保留推导所必需的核心代数概念。
11. 题链整体性与自然衔接：注重题链前后逻辑承接。若需说明研究目的或与前题联系，必须使用自然流畅的现代数学语言直接融入题干叙述中（例如"结合上题对对称变换的观察，我们进一步探讨……"），**严禁使用中括号机械标记**（严禁出现 `【研究目的：...】`、`【与前题联系：...】` 等）。若题目本身背景明确或无需额外过渡，亦可不写前置铺垫，直接提问，切忌形式主义与生硬套用。
12. 知识点陈列与列表规范：同一层级的多条定义、性质、推论陈列时，必须使用 LaTeX enumerate 环境分条展开（\item），保持平行规范，严禁堆砌无序段落；只有无序且极短要领才用 itemize。
13. 每节末必须有 `\begin{knowledgebox}[本节结论]...\end{knowledgebox}` 总结本节由问题链推出的结论（前置定义用实线 microknowledge；纯定理推导小节可以只保留结论框）。
14. **预算验证与提交**：提交前检查 `delivery_role` 字段是否完整；题目耗时由流水线确定性结构估算引擎自动计算，子 Agent 无需手动填写 `planned_minutes`。若 core 任务估算总时间超过 lesson_minutes 预算，流水线将提示超支，子 Agent 需在 result.json 中说明原因并提出合并或删除建议。（其余保持不变）
    ```json
    {"schema_version": 2, "run_id": "...", "task_id": "sec1",
     "attempt_id": 1, "input_digest": "...", "output": "sec1.tex",
     "output_sha256": "...", "notes": "完成状态、遇到的问题与材料缺口"}
    ```
    主 Agent 校验（身份一致、输入未变、哈希正确）后才会提升为正式切片；身份不符或输入已变的迟到结果一律拒收。

状态口径以 `../references/production.md` 状态词表为准：正文只使用 material-pack 中 `approved` 卡片；研究 Agent 的需求级 ACCEPT 只是初核建议，不等于批准。
```

#### 对话增强模式（TASK_MODE: dialogue-enhancement，config.yaml 启用对话层时适用）升级版

**【核心哲学】**：对话是印在纸面上的"思维避坑镜像"，绝非"真理剧透播报器"。角色负责踩坑、质疑与暴露盲区，真实学生负责在学案上计算、证明与裁决。

**【角色认知原型矩阵（Cognitive Misconception Matrix）】**：

| 角色代码 | 认知原型 | 典型思维特征与易犯错误 | 在避坑中的核心使命 | 禁区红线 |
|---|---|---|---|---|
| **$\Psi$ 或 $\tau$** | **启发导师 / 裁判** | 抛出看似自洽却隐藏危机的现象；控制讨论走向边界。 | 引导冲突，提出"违和感"，在双方僵持时将问题引向纸笔演算。 | **严禁给出现成公式、定理名称或最终结论**。 |
| **$\alpha$** | **几何经验派** | 依赖初等几何直观，容易把"保直线"、"保图形全等/相似"误当成代数上的"保线性结构"。 | **负责踩中"几何经验主义"陷阱**（如："平移保直线、保平行，凭什么不是线性映射？"）。 | 严禁代数化符号展开，只讲感性直观。 |
| **$\beta$** | **形式主义派** | 迷信符号表面形式，容易盲目泛化（例如认为所有函数都能像乘法一样分配，或把非线性映射强套矩阵）。 | **负责暴露"机械套用公式"的粗糙思维**（如："把自变量拆开算不就行了吗？"）。 | 严禁说出完全正确的推导恒等式。 |
| **$\gamma$** | **直觉质疑派** | 具有朴素反例直觉，能隐约察觉异常边界（如关注原点、零向量、边界维数），但缺乏严格证明工具。 | **负责指出直觉破绽与极端个案**（如："不对啊，平移之后零点变了，数乘怎么办？"）。 | 严禁给出完整证明，只负责"扎针"。 |

主 Agent 派发时在模板中追加以下固定字段并实际填充（不替子 Agent 写出台词结论）：

```text
TASK_MODE: dialogue-enhancement
SECTION_ID: <sec id>
SOURCE_FILES: <原文与 TeX 文件>
ENTRY_QID: <首个入口题 qid>
CORE_CONFLICT: <一个可观察冲突>
ROLES: $\Psi$（教师，固定） / $\alpha$ / $\gamma$ / $\beta$（学生，按需增删 $\kappa$/$\omega$/$\theta$；严禁 Teacher/Alpha 等英文名）
UNRESOLVED_AT_END: <对白结束必须留下的问题>
DOWNSTREAM_QIDS: <承接题号>
STUDENT_REVEAL: prompt_only | full
MAX_SECTION_TURNS: <默认 8，sectiondialogue 严格 4-6 句>
MAX_EXAMPLE_TURNS: <默认 6，exampledialogue 严格 3-4 句>
FORBIDDEN: 完整 solution、后续定理名称、未登记来源的新例子、全局文件编辑
REQUIRED_OUTPUTS: dialogue-brief, dialogue-script, TeX diff（候选切片）, dialogue-check
```

子 Agent 依次完成四阶段，每阶段产出可审查产物：

| 阶段 | 动作 | 必交产物 |
|---|---|---|
| 结构分析 | 读本节原文、题链和蓝图，找出一个核心冲突及其数学证据 | `dialogue-brief`：冲突、角色、未决问题、承接 qid |
| 脚本设计 | 按"冲突—暴露—对立—悬置"四步法设计回合，不写完整答案 | `dialogue-script`：逐句台词、角色动作、信息揭示位置 |
| TeX 嵌入 | 将脚本嵌入切片，保持 qid、题号与环境闭合 | 候选切片（dialogue 块 + 原题链） |
| 自检 | 运行 `scripts/check_dialogue.py` 并人工检查答案泄露、悬置末句、冲突密度 | `dialogue-check`：PASS/REVISE 及证据行号 |

**【硬性反剧透红线（触犯任一直接判 FAIL 驳回重写）】**：

1. **绝对零泄露（Zero Answer Leakage）**：
   - 严禁出现紧随其后的 ENTRY_QID 题目及其任意子问中 `\fillin[...]{...}[...]` 的参考答案（学生版按设计即可见选项，对错误干扰项的质疑不构成泄露；但不得在选项之外写出正确项，更不得借台词把选项肯定/否定到唯一正确项）。
   - 严禁在台词中写出矩阵乘法分配律恒等式（如 $A(\bm{u}+\bm{v})=A\bm{u}+A\bm{v}$）、导数线性恒等式、坐标投影具体计算展开式。
   - 严禁提及后续 microknowledge 或定理的正式名称与维度数值（如"零化度"、"核的维数是 1"等）。
2. **严禁逻辑完成态（No Completed Proofs）**：
   - 角色之间只能争论"可能是什么"、"为什么不对"，绝不允许任何角色给出一套完整的代数演绎链条。
3. **严禁无冲突平铺（No Monotonous Narration）**：
   - 禁止角色之间"相互捧哏"或复述公理。每个 dialogue 块必须有至少一个角色发表错误或片面直觉。

**【对话结构四步演进标准（"冲突—暴露—对立—悬置"）】**：

1. **第 1 步：锚定直观对象（Anchor）** — 教师/主持角色抛出一个具体且容易引发直觉判断的对象（例如：微积分求导、平面旋转、向量平移、空间投影）。
2. **第 2 步：诱发直觉踩坑（Pitfall Trigger）** — 角色 $\alpha$ 或 $\beta$ 依据初学者的典型前概念，大声说出一个**带有普遍代表性的错误断言**或**片面直觉**。
3. **第 3 步：认知阻击与对立（Friction & Doubt）** — 角色 $\gamma$ 或另一角色提出反常现象、特殊测试点（如代入 $\bm{0}$ 向量、考虑负标量、极端投影压扁），引发强烈认知冲突。双方各执一词，直觉解释破产。
4. **第 4 步：任务悬置收尾（Suspended Action）** — 结尾句必须**戛然而止**，把裁判权抛给下方的题目。典型收尾语境："究竟谁在凭感觉胡说？代数结构是否保持，必须在纸上写出展开式严格验算——我们代入定义算一算便知！" **绝对禁止**在末句公布正确答案。

**角色行为分工（写作时严格按认知原型执行）**：
- $\Psi$ 或 $\tau$：抛出具体研究对象与违和感（严禁总结结论）。
- $\alpha$（经验派）：依据几何直觉踩坑（"保直线/保图形全等，直观上绝对是线性的！"）。
- $\beta$（形式派）：机械套用符号，提出轻率假设（"直接按分配律拆开不就完了吗？"）。
- $\gamma$（怀疑派）：指出极端特例（如零向量去向、反例向量），引发激烈辩论。

对话写作硬规则（违反即退回）：
1. `\section*` 之后、首个实质题/定义之前放置且仅放置一个 `sectiondialogue`（sectiondialogue 严格 4-6 句）；首个入口题的 exampledialogue 放在 `\begin{probchain}` 之前，并以注释 `% dialogue: qid=<ENTRY_QID>` 绑定（exampledialogue 严格 3-4 句）。
2. 台词一律 `\speaker{角色}{台词}`，一句一个数学动作；会泄露答案的句子必须放入 `\dlgteacher{...}`；对话块内禁止 solution/teacherNote/`\fillin`/`\ansspace`。
3. 对话块末句必须是【设问句】或【指向计算检验的行动句】，以 `？`、`?`、`！`、`!` 结尾；若末句出现断言标志词（"由此可见"、"必然成立"、"所以答案是"、"显然等于"），视为违反悬置原则，判定失败。
4. 对话只能使用此前已定义的对象；需要新符号时先按现有规则插入最小 microknowledge。`proofstrategy` 方向性语言可出现，但不得提前写出待填答案；证明支架按方法新颖程度配置，策略段与分步题干不重复交代同一完整路线。
5. 每个 dialogue 块中必须包含至少 2 处认知冲突触发词（词表：凭什么、难道、为何、矛盾、不对、偏偏、并非、未必、破绽、疑问），缺乏冲突词说明对话沦为平铺直叙。
6. unprompted 题前不得配置 exampledialogue；对白若提供实质步骤，题目必须标 guided 并更新台账。
7. 对话块不得改变 probchain 计数与 qid；不得把教师版答案写进学生可见对白。

若发现跨 section 矛盾，标记 `CROSS-SECTION-BLOCKER` 交主 Agent 处理，不得自行修改其他 section 或全局表格。

执行时遵守以下硬性顺序：先核对叙事锚点、节点编号和原文锚点，再核对前置依赖，再写引例/材料和最小示例，最后写问题与答案。不得先写题目再倒推定义。每个题目只能有一个主要动作；证明题必须保留关键等式和逻辑方向。不能为了“完整题链”添加原文没有教学功能的反例题、迁移题或形式化题。

## 开篇引例子 Agent 模板（sec0.tex 专用）

是否派遣开篇专员由主 Agent 先判定（见 `../references/production.md` 步骤 3）：若第一节已承担开篇功能，允许合并职责或让 `sec0` 只保留极短必要背景；判定为需要独立开篇时，派遣一个专属子 Agent（Role：`"开篇引例与历史引入专员"`，同一低成本档位），候选输出固定为主 Agent 用 `pdstate.py start sec0` 创建的独占 attempt 目录（如 `self/.pd/candidates/sec0/attempt-0001/sec0.tex`，同目录提交 result.json；主 Agent 校验后提升为 `self/sec0.tex`）。

**入口约定先行**：开篇专员写作前先提交一份简短的“开篇—首节入口约定”草案，主 Agent 核定后冻结（记录于 `material-pack-sec0.md` 或章节总览，不另造台账）；写作必须使用冻结版本，首节切片共用同一份约定。约定字段：

1. 学生此时已知什么，能执行什么具体动作；
2. 开篇建立哪个观察，留下哪个尚未解决的问题；
3. 哪个答案可在开篇给出，哪个结论留到哪一节点（信息首次揭示位置）；
4. 首节如何使用开篇产物；重访同一实例时增加什么新动作。

```markdown
你是一名专职的数学教研子 Agent，负责撰写本章的开篇引例与历史引入切片（sec0.tex）。

## 输入约束
- 原材料文件：{{INPUT_FILE}}
- 本章标题：{{CHAPTER_TITLE}}
- 输出目标文件：独占 attempt 候选目录下的 sec0.tex（如 self/.pd/candidates/sec0/attempt-0001/sec0.tex，同目录提交复述四身份字段的 result.json；主 Agent 校验后提升为 self/sec0.tex）
- 开篇—首节入口约定：{{ENTRY_CONTRACT}}
- 已批准的开篇材料包（只读）：{{APPROVED_MATERIAL_PACK}}
- coverage-map.md 中的开篇素材登记记录：{{COVERAGE_OPENING}}
- 本章主线与第一小节入口：{{NEXT_BRIDGE}}

## 严格执行规范
0. 只能使用 {{APPROVED_MATERIAL_PACK}} 与 {{COVERAGE_OPENING}} 中状态为 `approved` 且已登记的素材；每个引例、反例与历史事实都必须可回溯到其中的来源记录，严禁自行编造来源、史实或数据。正文不得出现卡片 ID、来源核验标签或研究过程说明；材料包不足时返回缺口清单，不得自行检索。
1. 切片文件绝对不要包含 \documentclass、导言区或 \begin{document} / \end{document}。
2. 直接以 \section*{I {{CHAPTER_TITLE}}：引例与历史引入}（或主 Agent 指定的开篇标题）开头；开篇标题同样统一以大写罗马数字加空格（`I `）开头。
3. 本切片以叙述为主，较少使用问题：主体为 discussion/exposition 叙述段落，讲清引例所暴露的现象与它将导向的数学任务；至多穿插 1~2 道进入题帮助学生观察现象，严禁将本切片改造成完整题链，严禁提前给出本章定义、定理或结论。
4. 揭示顺序：严格遵守 {{ENTRY_CONTRACT}} 中“信息首次揭示位置”的约定。学生需要先判断后反馈的内容，按先操作、后核对的段落顺序呈现；不得在背景叙述中提前公布首个实质任务要学生自己得出的答案。原材料用 \pause 等手段分步给出问与答时，静态稿同样保留这一次序。
5. 历史断言限制：原文提到某人某事，不授权补出更具体的年代、因果或归属；无法核实的断言删除，历史背景不是本切片的强制组成部分。
6. 长度预算：默认至多使用 1 个主引例，仅当需要暴露旧方法边界时再加 1 个边界例。主口径为核心叙述不超过约 450 个汉字（不含公式字母），页数只作装配粗检；可删背景（历史、物理背景等）每则不超过 3 句。超出预算时按“删重复材料 → 合并同功能卡片 → 缩短背景为一句 → 删除历史材料”顺序裁剪，不得压缩字体或密集排版掩盖超长。
7. 前置规则：完成当前动作所需的语言必须在使用前明确（必要时用 microknowledge 卡片给出最小必要定义）；仅供导航的术语可少量点名，但不得成为解释当前现象的必要前提，也不得以“将在后续小节定义”豁免当前动作所需的前置。若引例必须先学本章新概念才能理解，返回缺口并建议简化对象或更换引例，不硬写。
8. 文风简明严谨与概念克制：使用严肃规范的书面数学语言，严禁口语化、戏谑、网络梗或夸张修辞；严禁脱离主线堆砌无关的高级概念。
9. 各段落的引例/历史注记必须写明其数学功能，且功能须落到可观察的前后差异：学生原先可能采用什么判断、看见哪组数据后会修正它、修正后的判断将在何处使用；与 coverage-map.md 的登记一致；无功能说明的素材不得写入。只改变故事对象、没有增加观察或方法边界的素材不写入。
10. 切片末尾用一段自然流畅的文字收束，衔接第一小节（依据 {{NEXT_BRIDGE}} 与 {{ENTRY_CONTRACT}} 留下的问题），严禁使用 `【研究目的：...】` 等机械中括号标签，严禁把章节总览中的定理清单复制为本章导读。
11. 将切片代码写入当前 attempt 候选目录（如 self/.pd/candidates/sec0/attempt-0001/sec0.tex）。不要修改任何其他文件。
```

主 Agent 核验 sec0.tex 时追加检查：素材来源是否全部可回溯、是否以叙述为主（问题不超过 2 道且均为进入题）、是否在长度预算内（约 450 汉字主口径）、是否遵守入口约定的信息首次揭示位置（未提前公布首节任务答案）、收束段是否衔接第一小节、是否引入超出约定的历史断言。核验后与首个实质任务一起提交独立教学验收（见 `prompts/acceptance_prompt.md`）。

---

10. 文风简明严谨与概念克制：全篇必须使用简明、严谨、严肃的数学学术文风，严禁使用口语化、戏谑调侃、网络梗或夸张修辞。
11. 题链整体性与自然衔接：注重题链前后逻辑承接。若需说明研究目的或与前题联系，必须使用自然流畅的现代数学语言直接融入题干叙述中。
12. 知识点陈列与列表规范：同一层级的多条定义、性质、推论陈列时，必须使用 LaTeX enumerate 环境分条展开。
13. 每节末必须有 `\begin{knowledgebox}[本节结论]...\end{knowledgebox}` 总结本节结论。
14. 将切片代码写入 {{OUTPUT_FILE}}...

主 Agent 在所有子 Agent 完成后，先核验内容再核验切片文件（按切片职责适用检查；开篇切片以叙述为主、可无完整题链，不强加普通题链要求）：
1. 每个题目的原文锚点是否明确，顺序是否保持；
2. 每个题目的依赖是否闭合，学生仅凭当前材料能否作答；
3. 原文命题和证明的关键论证是否保留，删改是否有记录；
4. 学习单元是否形成材料、问题、反馈和下一节点的闭环；
5. 是否存在为凑题型而增加的无效题目。**检查 `delivery_role` 字段完整性；题目用时由流水线确定性结构估算，无需手动比对编造的分钟数；验证 core 任务总数不超过预算限制（默认不超过 12 道核心题，若超过必须提出合并或删除建议）。未使用 `carrier_qid` 标记复用关系的重复载体题；self-study 题目出现在课堂必做清单；teacherNote 中存在大量重复的方法说明**。
随后检查切片文件：
6. 是否仅包含 `\section*{...}` 和 `\begin{probchain}`？（无 `\documentclass`、无重复导言）
7. 是否包含 `\qtype{...}`、`\ansspace{...}`、`solution`、`teacherNote`？
8. 是否严格遵守文风严肃克制、无网络热词口语梗、无依赖未经讲解的概念？
9. 题干是否自然流畅，绝无 `【研究目的：...】`、`【与前题联系：...】` 等机械中括号标签？
10. 标为 unprompted 的题是否确有主 Agent 台账中的示范题号/知识点 ID 依据，且题块内无提示行、引导性 microknowledge 或提示语？多小问负担不同时是否按需要支架的小问标 guided？缺定义的题是否被误判为无提示练习？
11. 材料回溯：切片中每个引例/反例/历史材料能否沿“正文 → 卡片 ID → research-brief.md 需求 → coverage-map.md 登记 → 来源摘录”完整回溯？是否只使用了 material-pack 中 `approved` 卡片，且正文未出现卡片 ID 或核验标签？
12. 材料预算：材料段落是否在 `research-brief.md` 的字数/卡片数/题目上限内？材料后是否立即出现可完成的数学动作？是否把后续小节内容提前讲完？任一失败则退回 `material-pack-secN.md` 重新裁剪，而不是要求子 Agent 继续润色超长切片。
13. 内容审校通过后，由主 Agent 确认子 Agent 已在 attempt 目录提交 result.json（四身份字段与输出哈希），再用 `pdstate.py submit` 将候选提升为正式切片，并在 `main.tex` 中 `\input{secN.tex}`，运行编译脚本完成装配。
14. 对话层（启用时）：切片是否含且仅含一个 `sectiondialogue`（位于 `\section*` 之后、首个实质题/定义之前），首个入口题是否有以 `% dialogue: qid=<入口题qid>` 绑定的 `exampledialogue`；台词是否遵守回合上限、每句一个数学动作、无答案泄露（泄露句必须在 `\dlgteacher` 内）；对白留下的未决问题是否被后续题目承接（无 `dialogue-orphan`）；结构由 `scripts/check_dialogue.py` 硬检查，泄露与孤立对白的教学判定归独立验收。
